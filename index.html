[ ABOUT THE FORGE ]

The workshop behind the work.

Overton Forge is the umbrella for Brandon Perry's creative and technical projects. It houses media essays, iOS and macOS software, automation systems, design assets, and public-interest tools — all from the same workshop, all sharing the same values.

The through-line is simple: preserve what matters, structure what's messy, and build tools that make people more capable instead of less. Some projects are media. Some are software. Some are experiments. All come from raw ore, get heated until the shape appears, and end up as finished artifacts in the archive.

[ HOW THE FORGE BUILDS ]

The bar.

  • 01

    Thoughtful artifacts, not disposable output.

    Work that feels intentionally made and worth returning to.

  • 02

    Control over black boxes.

    Every tool should expose what it's doing, not hide it behind smiling presets.

  • 03

    Memory with structure.

    Context preserved, not flattened. Receipts kept. Timelines clean.

  • 04

    Opinion with craft.

    Sharp, funny, critical when needed — but the finished work feels built, not sprayed onto the feed.

  • 05

    Systems that become usable things.

    No endless planning. Notes become artifacts. Workflows become tools. Ideas become public.
